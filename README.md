# 🧠 LeetCode Solutions

Auto-synced from my [LeetCode](https://leetcode.com) account using [leetcode-sync](https://github.com/joshcai/leetcode-sync).

Solutions are organized in the `solutions/` folder, grouped by problem name.

---

## ⚙️ Setup

This repo uses a GitHub Action that runs **every 6 hours** to pull any new submissions from LeetCode and commit them here automatically.

### Required Repository Secrets

| Secret                  | Description                                    |
| ----------------------- | ---------------------------------------------- |
| `LEETCODE_SESSION`      | Your `LEETCODE_SESSION` cookie from leetcode.com |
| `LEETCODE_CSRF_TOKEN`   | Your `csrftoken` cookie from leetcode.com        |

### How to Get the Cookies

1. Log in to [leetcode.com](https://leetcode.com)
2. Open **DevTools** → **Application** → **Cookies** → `https://leetcode.com`
3. Copy the values for `LEETCODE_SESSION` and `csrftoken`
4. Add them as **Repository Secrets** in **Settings → Secrets and variables → Actions**

### Workflow Permissions

Go to **Settings → Actions → General → Workflow permissions** and select **Read and write permissions**.
